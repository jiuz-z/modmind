结论（第五部分）

判定：C（本地 Agent 与云端 Agent 并存），但需精确化——
本机运行完整可执行的 Agent Runtime（Codex CLI + ModMind MCP 工具桥），云端主要负责 LLM 推理 + 账号/额度/中继 + 远端指令下发。
· 本地有 Agent：codexSetup.ts / externalAgents.ts（本地进程、工具循环、MCP 桥）
· 云端负责 LLM：设备凭证 relay baseUrl + apiKey，经本地 adapter 转发
· 云端另有“控制器型 Agent”：remoteClientService.ts / remoteAgentController.ts（WebSocket 下发指令，本机执行）
· 不存在“纯云端 Agent”：本机不存在的任何 Agent 循环环节在源码中均标记为【未知】，未猜测。
